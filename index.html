物流渠道判断助手

马帮 FBA 货件页悬浮面板：自动识别物流渠道、美国 5 货件分组、加拿大分区、德英货代选择，并支持自动生成发货单。

当前版本 v1.3.3

安装 / 更新

安装 / 更新脚本

点击后 Tampermonkey 会打开安装页，确认“安装”或“更新”即可。

使用前准备

  1. 浏览器先安装 Tampermonkey（篡改猴） 扩展。
  2. 点击上面的“安装 / 更新脚本”。
  3. 如果右下角没有“物流渠道”按钮：打开 Tampermonkey 管理面板 → 本脚本 → 设置 → 运行于 iframe → 选 所有 / All frames，保存后刷新马帮页面。
  4. 打开马帮 FBA 货件页，右下角出现蓝色“物流渠道”按钮即生效。

自动更新

  • 脚本头部已配置 @updateURL / @downloadURL。
  • Tampermonkey 默认每 24 小时检查一次更新；也可以在管理面板里点“检查更新”。
  • 发布新版本时，只要把脚本里的 @version 往上加（如 1.3.2 → 1.3.3）并提交，大家会自动收到更新。
如果脚本安装后读不到内层货件表格，八成是“运行于 iframe”没开。按上面第 3 步设置一次即可。
